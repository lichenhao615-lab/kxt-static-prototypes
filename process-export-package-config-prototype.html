资料项配置说明
表单用于承载业务字段、附件字段及可生成的资料项；资料项挂在一个或多个表单下维护，作为表单可对外输出的标准资料定义。
表单资料项挂在表单上统一维护，不只服务于资料包导出，也可被资料下载、合同签署等场景复用。
资料项类型为“模板”时，系统按模板 CODE 生成文件；资料项类型为“表单资料”时，直接读取表单附件字段。
资料项正文由系统模板能力维护，可通过导入 Excel、Word、PDF 文件覆盖当前正文；签署区和签名、盖章、签署日期等控件通过腾讯电子签嵌入式编辑页配置；系统保存资料项、模板 CODE、占位符和版本关系。
资料项生成方式由资料来源数量自动决定：只有一个文件时仅支持单个生成；存在多个文件时仅支持合并生成，并按资料来源顺序合并。
资料包配置挂在流程上，流程关联表单后，可从这些表单已维护的资料项中选择要导出的内容，并按资料包方案配置导出文件名、顺序和格式转换规则。
